# Inter release: the plan so far

The Inter release's plan, from the session that planned it. Not part of the release: never merge this folder.

- spec.md: the release spec, written and reviewed for data and look.
- review-findings.json: the data and look reviews' findings. The tests review hasn't run yet.
- release-args.json: the draft args for tools/release-workflow.js.
- map-*.md: the surveys of the board, the SDK and widgets, and the tests and docs.
- r-fonts/: the approved font page (page/index.html), its build recipe (page-work/build_fonts.py), and the Inter 4 sources with their license.
- calculator-letters-corrected.png: the approved Calculator letters, middle column.
- try/, sz/, italic2/: the font cutting experiments behind the spec.
- lang-1b-spec.md: the Languages 1b spec, which this release builds on.

Paths in these files that start with /tmp/claude-0/…/scratchpad/ were the planning session's. r-inter/ is now
plans/inter/, and r-fonts/ is plans/inter/r-fonts/.
